# Python Projects

This repository contains my collection of Python projects developed while learning the language. Each project focuses on different concepts like loops, data structures, and logic building.

## Projects

### 1. Calculator
A simple command-line calculator built using Python.
- **Concepts:** Functions, Basic Arithmetic, Input Validation.
- **Features:** Addition, Subtraction, Multiplication, Division.

### 2. Number Guessing Game
A fun game where the computer selects a number, and the user guesses it with limited attempts.
- **Concepts:** `random` module, `while` loops, `if-elif-else` conditions.
- **Features:** Random number generation, Attempt counter, High/Low feedback.

### 3. Password Generator
A tool to generate random, secure passwords based on user-defined length.
- **Concepts:** `string` module, Random selection, String manipulation.
- **Features:** Includes ASCII letters, digits, and special characters.

### 4. Expense Tracker
A personal finance tool to keep track of daily expenses.
- **Concepts:** Lists, Dictionaries, Loops.
- **Features:** Add expenses, View history, Calculate total spending.

### 5. Quiz App
An interactive quiz game to test knowledge.
- **Concepts:** List of Dictionaries, User Input, Scoring logic.
- **Features:** Multiple-choice questions, Real-time score tracking, Result display.
